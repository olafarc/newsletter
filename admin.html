OLAFNEWS — Panel

Panel privado para publicar entradas nuevas sin tocar código. No está enlazado desde la portada.

1 · Conexión con tu repositorio

Si no marcás la casilla, vas a tener que pegar el token de nuevo cada vez. Nunca lo compartas ni lo pegues en otro sitio.
¿Cómo genero el token?
  1. Andá a GitHub → tu foto de perfil → Settings.
  2. Bajá hasta Developer settings (al final del menú izquierdo).
  3. Entrá a Personal access tokens → Fine-grained tokens → Generate new token.
  4. En "Repository access" elegí Only select repositories y seleccioná el repo de esta página.
  5. En "Permissions" buscá Contents y ponelo en Read and write.
  6. Generá el token y copialo — GitHub solo te lo muestra una vez. Pegalo arriba.

2 · Nueva entrada

Cada párrafo separado por una línea en blanco se muestra como un párrafo distinto.
Subí un archivo o pegá una URL de imagen. Con exactamente 3 fotos se muestran en fila; con otra cantidad, apiladas. El epígrafe es el pie de foto (opcional).
